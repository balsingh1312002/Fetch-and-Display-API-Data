Fetch and Display API Data
🎯 Objective

Fetch user data from a public API and display it dynamically on the frontend using HTML, CSS, and JavaScript.

🔗 API Endpoint

JSONPlaceholder Users API

text
https://jsonplaceholder.typicode.com/users

📌 Features
Fetch user data using the JavaScript fetch() API.
Handle asynchronous operations using async/await.
Display user details dynamically on the webpage.
Use HTML for structure, CSS for styling, and JavaScript for functionality.
Create a clean, user-friendly, and mobile-responsive interface.
Handle API errors gracefully.
🛠️ Technologies Used
HTML5 – Structure of the webpage.
CSS3 – Styling and responsive design.
JavaScript (ES6+) – API fetching, async/await, and DOM manipulation.
JSONPlaceholder API – Provides sample user data.
📂 Project Structure
text
fetch-api-data/
├── index.html
├── style.css
├── script.js
└── README.md

⚙️ How It Works
Send a request to the JSONPlaceholder API using fetch().
Use async/await to handle the asynchronous response.
Convert the response into JSON format.
Extract user details from the API response.
Display the user data dynamically on the webpage.
Handle errors if the API request fails.
🚀 Getting Started
Clone this repository:
bash
git clone <your-repository-url>

Navigate to the project folder:
bash
cd fetch-api-data

Open index.html in your browser, or run the project using the Live Server extension in Visual Studio Code.
